# 《京爷的一天》/ BJMan

一个 Web + 文字互动游戏，主题是“北京老炮 / 京味中年 / 当代城市边缘人”的一天。

## 玩法（当前版本）
- 5 个时间阶段：早上、上午、中午、下午、晚上。
- 5 个核心变量：面子、钱、关系、精力、心气。
- 场景来自事件包（主线 + 扩展包），会根据你前面的选择动态分支。
- 选择包含即时变化，也可能埋下“延迟后果”，在后续阶段触发。
- 连续两回合负收益时，会出现一次“微希望”修复选项。
- 一天结束后触发多结局，并给出“关键转折”复盘。

## 本地运行（游戏）
直接打开 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
```

访问 <http://localhost:8000>。

## 场景数据
- `scenes.js`：按 `SCENE_PACKS` 组织场景事件包（可持续新增）。
- `game.js`：负责分支调度、延迟后果结算、结局判定与复盘展示。

## 单独更新页面
新增 `update.html` + `update-server.js`，用于在项目目录执行 `git pull`。

启动方式：

```bash
node update-server.js
```

打开：<http://localhost:8787/update.html>

点击页面里的 **拉取更新** 按钮后，后端会执行 `git pull` 并把命令输出显示在页面上。
