# 《京爷的一天》/ BJMan

一个 Web + 文字互动游戏 MVP，主题是“北京老炮 / 京味中年 / 当代城市边缘人”的一天。

## 玩法
- 5 个场景：早上、上午、中午、下午、晚上。
- 5 个核心变量：Face、Money、Relation、Energy、Mood。
- 每个场景提供 2～3 个都不完美的选项。
- 一天结束后基于整体状态触发 3 个结局：
  - 撑过去了
  - 有点绷不住
  - 今天算是塌了

## 本地运行
直接打开 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
```

访问 <http://localhost:8000>。
